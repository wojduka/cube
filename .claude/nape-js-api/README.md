# nape-js API

Local copy of the [nape-js API reference](https://napejs.org/api/) for `@newkrok/nape-js`.
Fetched 2026-11-26. This project depends on `@newkrok/nape-js` 3.43.5.

Read the page for a symbol before using it. `Polygon.box` returns a rectangle centred on the body origin. Add a body with `body.space = space`.

The same tree is in `.cursor/nape-js-api/` and `.claude/nape-js-api/`.
