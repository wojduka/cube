# cube

A small TypeScript canvas starter. `npm start` compiles `src/main.ts` to `dist/main.js` and serves that folder, so the browser loads the compiled JavaScript.

## Run

```bash
git clone https://github.com/wojduka/cube.git ~/pjs/cube
cd ~/pjs/cube
npm install
npm start
```

Then open http://localhost:3000

`npm run build` only compiles. `npm run dev` watches TypeScript and recompiles into `dist/`.
